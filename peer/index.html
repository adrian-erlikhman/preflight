Preflight

Portable agent network

spec_helper

A two-agent network that answers questions about the Worldwide Agentic Web MVP spec and drafts the files an open agentic website must publish. It has no website actions, so any agentic website can load it as a peer and run it in its visitors' browsers, with their router and key.

Use it from your network

"tools": ["https://adrian-erlikhman.github.io/preflight/peer/spec_helper"]

Add the origin https://adrian-erlikhman.github.io to your manifest's allowed_peers, or bind the URL to a name in your links.json.
