    How it works

    Reads your site like a peer

    A site that loads your agents fetches your manifest and network file from its own origin. Preflight does the same: cross-origin, no cookies, CORS enforced by the browser. When a file is blocked, it tells a missing CORS header apart from a missing file.

    Validates with the reference runtime

    Each network is parsed and validated by the same code the reference browser runtime runs, then checked against every requirement in the spec that a published site can be tested for: files, front agent, schemas, peer URLs, peer policy, private context and credentials.

    Explains and tests live

    The assistant turns failures into plain fixes and corrected files. With your consent it loads the checked network as a peer and runs it here, with your router and key. The key goes only to your router, never to the site under test.

    What a pass means

    • Publishes a valid network: manifest and network file exist, parse, and pass the runtime's validator, with a front agent that matches.
    • Readable from other origins: both files load cross-origin, so a caller's browser can fetch them.
    • Runs when another site loads it: the network is data only and does not depend on actions that exist only on your page.
    • No credentials in public files: no API keys, tokens or passwords in anything you publish.

    Preflight checks what a published site can show from the outside. It cannot see server-side code, response headers the browser hides, or how a runtime behaves under load. Required and recommended levels follow the spec's MUST and SHOULD.

    For other agentic websites

    Preflight publishes a second, portable network for other sites to load as a peer. spec_helper answers questions about the MVP spec and drafts the files it requires. It does not depend on this page, so it runs the same way in any caller's browser.

    "tools": ["https://adrian-erlikhman.github.io/preflight/peer/spec_helper"]

    Add that URL to one of your agents' tools, and its origin to your manifest's allowed_peers. Your visitors' router and key run it; nothing is sent to this site.
